# Website assets

- `apps/web/public/images/archive-drawer.webp`: AI-generated hero artwork for the
  production landing page: a dark wall of card-catalog drawers with one drawer
  open and a single index card lit amber, standing for the source note behind
  each answer. Supplied by the project owner October 23, 2026, at 1672 × 941
  WebP. It replaces the earlier dithered archive landscape (`signal-landscape.webp`).
- `apps/web/public/fonts/geist-variable.woff2` and
  `geistmono-variable.woff2`: Geist and Geist Mono Latin variable fonts,
  distributed through [Fontsource](https://fontsource.org/fonts/geist) under
  SIL Open Font License. The upstream license notices from Google Fonts are
  retained as `GEIST-LICENSE.txt` and `GEISTMONO-LICENSE.txt`. The website
  self-hosts these fonts without runtime third-party requests.

- `apps/web/public/images/courtyard.webp`: AI-generated architectural artwork.
  Derived from the Groundray hero approved by the project owner, with all
  lettering removed and re-created as accessible HTML. Generated October 20,
  2026. Exported to WebP at the original 1672 × 941 resolution.
- `apps/web/public/favicon.svg`: Groundray ray mark, drawn as SVG for this page.
- `apps/web/public/fonts/instrument-serif*.woff2`: Instrument Serif, regular and
  italic Latin subsets, distributed by Google Fonts under the SIL Open Font
  License. License: `INSTRUMENT-SERIF-LICENSE.txt` in that directory.
  Upstream: https://github.com/google/fonts/tree/main/ofl/instrumentserif
- `apps/web/public/fonts/manrope-latin.woff2`: Manrope variable Latin subset,
  weights 400–700, distributed by Google Fonts under the SIL Open Font License.
  License: `MANROPE-LICENSE.txt` in that directory.
  Upstream: https://github.com/google/fonts/tree/main/ofl/manrope

- `apps/web/public/images/tools/codex.png`: Codex app icon from OpenAI’s
  [Codex product page](https://openai.com/codex/), downloaded from its official
  [asset CDN](https://images.ctfassets.net/kftzwdyauwt9/YgXvGzKvVcDvpJGOFyroe/777616dd860276400c9c955688dce373/codex-app.png.png?w=128&fm=png).
- `apps/web/public/images/tools/claude-code.png`: Claude mark from the official
  [Claude Code documentation](https://code.claude.com/docs/en/overview), using its
  [published app icon](https://code.claude.com/docs/_mintlify/favicons/claude-code/pLsy-mRpNksna2sx/_generated/favicon/android-chrome-192x192.png).
  Both product marks identify supported tools and are self-hosted unchanged.
  Retrieved October 20, 2026. The Terminal symbol uses the existing Lucide icon.
- `apps/web/public/images/tools/{openai,claude,cursor,gemini,opencode}-mark.svg`:
  monochrome brand marks from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons),
  distributed under MIT; the notice is retained as `tools/LOBE-ICONS-LICENSE.txt`.
  Rendered as single-color masks for a consistent, unboxed hero row. The OpenAI
  mark identifies Codex; Cursor, Gemini CLI, and OpenCode use Groundray through
  terminal access rather than native plugin packages. Retrieved October 20, 2026.
