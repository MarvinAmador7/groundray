# Mosaic Studio with CLI-managed original sources

This is the saved file snapshot from the
[CLI-only source demonstration](../../docs/groundray-cli-sources.md), using 21
fictional records and three root-authored knowledge drafts. Source copying and
inspection use `pkb source capture/get`; no original source bytes are rewritten.
No real owner approval or human verification is recorded.

Start with [navigation](knowledge/index.md),
[pricing](knowledge/wiki/lumen-commercial.md),
[October margin](knowledge/wiki/lumen-margin.md) or
[launch/Tint scope](knowledge/wiki/lumen-launch.md).
Original copies and their adjacent receipts live under
`knowledge/references/captures/`; the [mapping](source-captures.json) relates
them to the unchanged supplied packet. Markdown originals have `.md.txt` names.
Internal links within original captures are preserved as data, not automatically repaired.

This nested snapshot is not a standalone Git repository. Follow the
[reproduction instructions](../../docs/groundray-cli-sources.md#reproduce) to
create the installable company repository with its history and isolated configs.
The [full trace](../../evals/groundray/results/2026-10-12-groundray-cli-sources-v1/trace.json)
and [result](../../evals/groundray/results/2026-10-12-groundray-cli-sources-v1/result.json)
preserve observed commands, hashes, versions and limits. The snapshot alone has
no Git history; the generated company repository retains both cited versions.
